Introduction & History of CSS

What CSS is, who invented it, and why every website needs it

What is CSS?

CSS stands for Cascading Style Sheets — the language used to describe how HTML elements should look: colour, spacing, layout, fonts and motion. HTML gives a page its structure and meaning; CSS gives it presentation.

Definition A style sheet is a set of rules, each made of a selector (what to style) and a declaration block (how to style it). CSS applies these rules to HTML elements to control their appearance.

The Web Trio

🧱 HTML — StructureThe walls & rooms of a house. Defines layout and content.
🎨 CSS — StyleThe paint, furniture & decoration. Controls appearance.
⚡ JS — LogicThe lights, fans & interactivity. Controls behaviour.

Who Created CSS?

CSS was proposed by Håkon Wium Lie, a Norwegian developer working alongside Tim Berners-Lee's team, as a way to let authors style documents without mixing presentation into the markup itself. It was later developed and standardised by the World Wide Web Consortium (W3C) — the same body that maintains HTML.

Why it was needed Before CSS, styling was done with presentational HTML tags like <font> mixed directly into the markup. That made pages bloated and painful to maintain — one design change meant editing every page by hand.

Breaking Down the Name

  • Cascading — when multiple rules target the same element, CSS resolves conflicts in a predictable order (source order, specificity, !important).
  • Style — the visual appearance given to an HTML element.
  • Sheets — a collection of style rules, usually saved as a .css file.

CSS Today — Where It's Used

Modern CSS is split into independent modules (Flexbox, Grid, Animations, Custom Properties, Media Queries) so each part can evolve on its own — informally this whole modern era is what people mean by "CSS3." Every modern browser (Chrome, Firefox, Safari, Edge) supports the vast majority of current CSS, and almost every website on the internet is styled with it — often together with a framework like Tailwind CSS or Bootstrap, or a preprocessor like Sass, which compiles down to plain CSS.

Basic Syntax

selector {
  property: value;
}

/* example */
h1 {
  color: navy;
  font-size: 32px;
}

Comments are written as /* like this */ and are ignored by the browser.

Ways to Add CSS

Inline, internal, external — and which rule wins when they conflict

1. Inline CSS

Written directly on an element using the style attribute. Good for quick tests, bad for real projects — it can't be reused and is hard to maintain.

<p style="color:#009900; font-size:20px;">Hello</p>

2. Internal CSS

Written inside a <style> tag in the document's <head>. Useful for single-page demos, but doesn't scale across a multi-page site.

<head>
  <style>
    h1 { color: green; }
  </style>
</head>

3. External CSS

Best Practice Write CSS in a separate .css file and link it with <link>. One stylesheet can then style many pages, and HTML stays clean and readable. 
<link rel="stylesheet" href="style.css">

A fourth, less common option is @import, which pulls one stylesheet into another from inside CSS itself — including remote resources like Google Fonts.

@import url('https://fonts.googleapis.com/css2?family=Poppins&display=swap');

Which One Wins?

When the same property is set in more than one place, CSS applies this order of priority:

Inline CSS > Internal / External CSS (later rule wins if equal specificity) > Browser default styles.

Careful A rule marked !important overrides everything above — including inline styles. It's a useful escape hatch, but overusing it makes future CSS changes much harder to reason about.

CSS Selectors

Targeting exactly the elements you want to style

Basic Selectors

SelectorSyntaxSelects
Universal*every element on the page
Element / tagp, h1, divevery element of that tag
Class.cardevery element with class="card"
ID#herothe one element with that unique id
Grouph1, h2, papplies one rule to several selectors at once
Attributeinput[type="text"]elements matching an attribute value

Combinators — Describing Relationships

  • div p — descendant: any p nested anywhere inside a div
  • div > p — child: only a p that is a direct child of div
  • div + p — adjacent sibling: the p immediately after a div
  • div ~ p — general sibling: every matching sibling that comes after the div
.card p   { background: red; }   /* descendant */
.card > p { background: aqua; }  /* direct child only */

Specificity — Who Wins?

When two rules target the same element, the browser scores each selector and applies the more specific one: inline style > ID > class / attribute / pseudo-class > element. Equal specificity is resolved by whichever rule appears later in the stylesheet.

Best Practice Style with classes, not IDs. IDs carry very high specificity and make later overrides painful — save ids for JavaScript hooks and unique page anchors, not styling.
MODULE 04 / 18  ·  SELECTORS

Pseudo-classes & Pseudo-elements

Styling states, positions, and generated content

Pseudo-classes — a State or Condition

a:hover      { color: crimson; }
input:focus   { outline: 2px solid teal; }
li:first-child { font-weight: bold; }
li:nth-child(2) { color: royalblue; }
input:disabled { opacity: .5; }

Pseudo-elements — a Part of an Element

p::first-letter { font-size: 2em; }
p::selection    { background: yellow; }
.badge::before  { content: "★ "; }
.badge::after   { content: " New"; }
Rule of thumb A single colon (:hover) is a pseudo-class — a state. A double colon (::before) is a pseudo-element — a generated part of the element.

Common pseudo-classes to remember

  • :hover
  • :focus
  • :active
  • :visited
  • :first-child / :last-child
  • :nth-child()
  • :checked
  • :disabled / :not()

Background Properties

Gradients

.radial { background-image: radial-gradient(circle, white, purple); }

Text Formatting

  • text-decoration — none / underline / line-through / overline
  • text-transform — uppercase / lowercase / capitalize

  • text-shadow: 2px 2px 4px rgba(0,0,0,.4);

MODULE 07 / 18  ·  LAYOUT FOUNDATIONS

The Box Model

Every HTML element is a rectangular box — margin, border, padding, content
margin
border
padding
content

The Four Layers, Outside In

  • Margin — transparent space outside the border, separating an element from its neighbours.
  • Border — a visible (or invisible) line around the padding.
  • Padding — space inside the border, between the border and the content.
  • Content — the actual text, image, or nested elements.
.box {
  width: 200px;
  height: 100px;
  padding: 20px;
  border: 4px solid #333;
  margin: 16px;
}

box-sizing

By default (content-box), width/height apply only to the content — padding and border are added on top, so the element renders larger than the numbers suggest. Switching to border-box makes width/height include padding and border, which is far more predictable.

*, *::before, *::after {
  box-sizing: border-box; /* common global reset */
}

Shorthand Order

margin, padding and border-radius shorthand values go clockwise: top, right, bottom, left.

margin: 10px 20px;        /* top&bottom: 10px, left&right: 20px */
margin: 7px 10px 5px 9px; /* top right bottom left            */
border-radius: 12px 12px 0 0; /* rounded top corners only */

Display & Position

How an element behaves in the flow, and where it sits on the page

Display

ValueBehaviour
blockstarts on a new line, takes the full available width
inlineflows with surrounding text, ignores width/height
inline-blockflows inline, but accepts width, height, margin & padding
noneremoves the element from the page entirely (no space reserved)

visibility:hidden hides an element but still reserves its space — unlike display:none.

Position

ValueBehaviour
staticdefault; ignores top/left/right/bottom
relativemoves relative to its own normal position; original space preserved
absoluteremoved from normal flow; positioned relative to nearest positioned ancestor
fixedpositioned relative to the browser viewport; stays put on scroll
stickybehaves like relative, then "sticks" like fixed after a scroll threshold
.badge { position: absolute; top: -8px; right: -8px; }
.parent { position: relative; } /* gives .badge something to anchor to */

z-index & Overflow

z-index controls stacking order of overlapping elements — higher values sit above lower ones — but only works on positioned elements (anything other than static). overflow controls content bigger than its box: visible (default), hidden, scroll, or auto.

CSS Units

Choosing units that make a layout scale gracefully

Absolute vs Relative

UnitTypeRelative to
pxabsolutefixed pixel size, doesn't scale
%relativethe parent element's size
emrelativethe current/parent element's font-size
remrelativethe root <html> font-size — predictable across components
vw / vhrelative1% of the viewport's width / height
vmin / vmaxrelativethe smaller / larger of vw & vh — useful on rotation
Example If the root font-size is 16px, 2rem is always 32px no matter how deeply nested the element is — whereas 2em depends on its own parent, so it can compound unexpectedly in nested components.

Modern Fluid Sizing

font-size: clamp(1.5rem, 4vw, 3rem);
/* clamp(minimum, preferred/fluid, maximum) */

width: min(92%, 1200px);   /* whichever is smaller */
height: max(300px, 40vh);  /* whichever is larger  */
Best Practice clamp() is the modern replacement for writing several media queries just to resize a heading responsively.
MODULE 10 / 18  ·  LAYOUT SYSTEMS

Flexbox

One-dimensional layout — the go-to tool for navbars, toolbars & alignment

Setting Up a Flex Container

.container {
  display: flex;              /* row is the default direction */
  flex-direction: row;        /* row | row-reverse | column | column-reverse */
  justify-content: center;    /* aligns along the MAIN axis */
  align-items: center;        /* aligns along the CROSS axis */
  flex-wrap: wrap;            /* allow items to wrap */
  gap: 20px;                  /* space between items */
}

Main Axis vs Cross Axis

In row direction, the main axis runs horizontally and justify-content controls it; the cross axis runs vertically and align-items controls it. Switching to column swaps the two axes.

justify-contentEffect
flex-start / flex-enditems pushed to one edge
centeritems centred
space-betweenfirst/last touch the edges, equal gaps between
space-aroundequal space around each item
space-evenlyperfectly equal space everywhere, including the ends

Per-item Properties

.item {
  order: 2;           /* re-orders visually without touching HTML */
  flex-grow: 1;       /* how much it expands to fill space */
  flex-shrink: 0;     /* whether it's allowed to shrink */
  flex-basis: 200px;  /* starting size before grow/shrink apply */
  align-self: flex-end; /* overrides align-items for one item */
}
MODULE 11 / 18  ·  LAYOUT SYSTEMS

CSS Grid

Two-dimensional layout — rows and columns together, for full page layouts

Basic Grid

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* 3 equal columns */
  grid-template-rows: auto auto;
  gap: 20px;
}

The fr unit divides remaining free space proportionally, after any fixed-size tracks are subtracted.

Placing Items & Areas

.item {
  grid-column: 1 / 3;   /* spans from line 1 to line 3 */
  grid-row: 2;
}
.container {
  grid-template-areas:
    "sidebar header"
    "sidebar main";
}
.sidebar { grid-area: sidebar; }

Responsive Grid Without Media Queries

.container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 20px;
}
Flexbox vs Grid Flexbox is one-dimensional and content-driven — great for a navbar or a button group. Grid is two-dimensional and layout-driven — great for the whole page skeleton.

Lists, Tables & Forms

Restyling the three elements with the heaviest browser defaults

Lists

ul {
  list-style-type: none;  /* disc | circle | square | decimal | none */
  padding: 0;
}
li { margin-bottom: 8px; }

Tables

table { border-collapse: collapse; width: 100%; }
th, td { border: 1px solid #ddd; padding: 10px; text-align: left; }
thead { background: #f4f4f4; }
tr:nth-child(even) { background: #fafafa; } /* zebra striping */

Structure: <table> → <thead> (headings) & <tbody> (data rows) → <tr> (row) → <th> / <td> (header / data cell).

Forms

input, textarea, select {
  padding: 10px 14px;
  border: 1px solid #ccc;
  border-radius: 8px;
  font: inherit;
}
input:focus {
  outline: none;
  border-color: #2563eb;
  box-shadow: 0 0 0 3px rgba(37,99,235,.2);
}
button:disabled { opacity: .5; cursor: not-allowed; }
Accessibility Always keep a visible focus style — removing it without a replacement makes a form unusable for people navigating with a keyboard.
MODULE 13 / 18  ·  RESPONSIVE DESIGN

Responsive Design & Media Queries

Making one layout adapt from a small phone to a wide desktop monitor

The Viewport Meta Tag

Without this tag, mobile browsers render the page at desktop width and zoom out.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Mobile-first Media Queries

Write base CSS for small screens first, then layer on bigger-screen rules with min-width queries as the canvas grows.

/* base styles = mobile */
.container { display: block; }

@media (min-width: 768px) {   /* tablet and up */
  .container { display: flex; }
}
@media (min-width: 1200px) {  /* desktop and up */
  .container { max-width: 1140px; margin: 0 auto; }
}

Responsive Images & Fluid Containers

img { max-width: 100%; height: auto; display: block; }
.container { width: min(92%, 1200px); margin: 0 auto; }

Common breakpoints: roughly 480px (mobile), 768px (tablet), 1200px (desktop) — but the right breakpoint is always wherever your own design starts to look cramped.

MODULE 14 / 18  ·  MOTION

Transitions, Transforms & Animation

Bringing a page to life without JavaScript

Transition — Smoothing a State Change

button {
  background: #2563eb;
  transition: transform .2s ease, background .2s ease;
}
button:hover {
  transform: translateY(-3px);
  background: #1d4ed8;
}

A transition needs a property, a duration, and optionally a timing-function and delay. It only runs between two states.

Transform — Move, Rotate, Scale, Skew

.card:hover {
  transform: translateY(-8px) scale(1.03) rotate(1deg);
}
.tilt-3d {
  transform: perspective(800px) rotateX(15deg) rotateY(-10deg);
}

Transforms don't affect normal page flow (no other element moves), which makes them fast and ideal for hover effects.

Animation — Multi-step Motion with @keyframes

@keyframes pulse {
  0%   { transform: scale(1); }
  50%  { transform: scale(1.08); }
  100% { transform: scale(1); }
}
.badge { animation: pulse 1.5s ease-in-out infinite; }
Transition vs Animation Transition only moves between two states (usually default → hover). Animation can define any number of stopping points with @keyframes and can run automatically, without a hover or click to trigger it.

CSS Custom Properties (Variables)

  --primary: #6c5ce7;

calc(), filter, object-fit & More

filter: blur(4px) brightness(1.1) saturate(1.2);
img { object-fit: cover; }        /* crop image to fill box */
.clip { clip-path: circle(50%); } /* cut a custom shape */

Glassmorphism & Shadows

box-shadow: 0 10px 30px rgba(0,0,0,.15);

.glass {
  background: rgba(255,255,255,.18);
  backdrop-filter: blur(14px);
  border: 1px solid rgba(255,255,255,.3);
}

CSS Architecture — Naming with BEM

.card { }              /* Block */
.card__title { }       /* Element */
.card--featured { }    /* Modifier */

Frameworks & Preprocessors

BootstrapReady-made components: navbars, cards, grid system.
Tailwind CSSUtility classes composed directly in HTML.
Sass / LessPreprocessors — variables, nesting, functions, compiled to plain CSS.
Debugging tip Open browser DevTools (F12) and use the Elements panel — it shows every rule applying to a selected element, with overridden rules struck through, plus a live box-model diagram.

5 full, buildable projects that combine everything covered so far

Mini Project 1 — Profile Card

A centred card with an avatar, name, role and a follow button — practises the box model, border-radius, box-shadow and Flexbox centring.

body { display: flex; justify-content: center; align-items: center; min-height: 100vh; background: #f0f2f5; }
.card {
  width: 280px; text-align: center; background: #fff;
  border-radius: 16px; box-shadow: 0 10px 30px rgba(0,0,0,.12); padding: 30px 20px;
}
.card img { width: 90px; height: 90px; border-radius: 50%; object-fit: cover; }
.card button { margin-top: 14px; padding: 10px 24px; border-radius: 999px; border: none; background: #2563eb; color: #fff; }
Key concepts used: flex centring · circular image with object-fit · box-shadow · rounded pill button

Mini Project 2 — Login Form

A styled login form with labelled inputs, visible focus states and a disabled-state submit button.

.login { width: 320px; margin: 80px auto; padding: 30px; border-radius: 14px; box-shadow: 0 8px 24px rgba(0,0,0,.1); }
.login label { display: block; font-size: .85rem; margin-bottom: 6px; }
.login input { width: 100%; padding: 10px 12px; margin-bottom: 18px; border: 1px solid #ccc; border-radius: 8px; }
.login input:focus { border-color: #2563eb; outline: none; box-shadow: 0 0 0 3px rgba(37,99,235,.2); }
Key concepts used: forms · box model · :focus pseudo-class · box-shadow rings

Mini Project 3 — Product Card Grid

A responsive grid of product cards, each lifting on hover.

.grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(220px, 1fr)); gap: 20px; }
.product { background: #fff; border-radius: 12px; overflow: hidden; box-shadow: 0 6px 18px rgba(0,0,0,.08); transition: transform .2s ease; }
.product:hover { transform: translateY(-6px); }
Key concepts used: CSS Grid auto-fit/minmax · transition + transform hover · overflow:hidden for rounded images

Mini Project 4 — Restaurant Landing Page

A full page: sticky navbar, hero section, a menu table, and a footer with contact links.

.navbar { position: sticky; top: 0; display: flex; justify-content: space-between; align-items: center; padding: 16px 40px; background: #14213D; }
.hero { min-height: 70vh; display: flex; flex-direction: column; justify-content: center; align-items: center; text-align: center; background: url("hero.jpg") center/cover; }
.menu table { width: 100%; border-collapse: collapse; }
Key concepts used: position:sticky navbar · flex hero centring · background-size:cover · table styling

Mini Project 5 — Responsive Pricing Section

Three pricing cards in a grid, with a "featured" modifier class that highlights the middle plan.

.pricing { display: grid; grid-template-columns: repeat(auto-fit, minmax(240px, 1fr)); gap: 24px; }
.plan--featured { transform: scale(1.05); border: 2px solid #6c5ce7; }
@media (max-width: 600px) { .plan--featured { transform: none; } }
Key concepts used: responsive grid · BEM modifier class · media query overriding a transform on small screens
MODULE 17 / 18  ·  INTERVIEW PREP

Interview Questions

30 beginner-friendly CSS questions asked in real interviews

Questions 1–6

1What does CSS stand for?
Cascading Style Sheets.
2Who created CSS?
Håkon Wium Lie proposed it; it was standardised by the W3C.
3What does "cascading" mean in CSS?
Conflicting rules are resolved in a predictable order: source order, specificity, then !important.
4What are the three ways to add CSS?
Inline, internal (in a <style> tag), and external (a linked .css file).
5Which type of CSS has the highest priority?
Inline CSS — unless a rule elsewhere uses !important.
6What is a CSS selector?
A pattern used to target the HTML element(s) a rule should apply to.

Questions 7–12

7Difference between class and id selectors?
A class can be reused on many elements; an id must be unique to one element per page.
8What is specificity?
A scoring system deciding which rule wins when several target the same element.
9Difference between a pseudo-class and a pseudo-element?
A pseudo-class (:hover) targets a state; a pseudo-element (::before) targets a generated part of an element.
10What does the box model consist of?
Content, padding, border and margin, from the inside out.
11What does box-sizing: border-box do?
Makes width/height include padding and border, instead of adding them on top.
12Difference between margin and padding?
Margin is space outside an element's border; padding is space inside it, before the content.

Questions 13–18

13Difference between block, inline and inline-block?
Block takes full width and starts a new line; inline flows with text and ignores size; inline-block flows inline but accepts width/height.
14Difference between position:relative and position:absolute?
Relative shifts an element from its own position and keeps its space; absolute removes it from flow and positions it against the nearest positioned ancestor.
15What does z-index require to work?
The element must have a position value other than static.
16Difference between em and rem?
em is relative to the parent's font-size; rem is relative to the root <html> font-size.
17What is the difference between visibility:hidden and display:none?
visibility:hidden hides an element but keeps its space; display:none removes it entirely.
18What is the purpose of the viewport meta tag?
Makes a page render at the correct scale on mobile devices instead of zoomed-out desktop width.

Questions 19–24

19What is Flexbox used for?
One-dimensional layout — aligning items in a single row or column.
20What is the main axis in Flexbox?
The primary direction items are laid out in — horizontal by default (row), controlled by justify-content.
21When would you choose Grid over Flexbox?
When you need to control layout in two dimensions (rows and columns) at once, like a full page skeleton.
22What does the fr unit mean in CSS Grid?
A fraction of the remaining free space in the grid container.
23What is a media query?
A CSS rule that applies styles only when a condition, like a minimum viewport width, is met.
24What does "mobile-first" mean?
Writing base CSS for small screens first, then adding larger-screen rules with min-width media queries.

Questions 25–30

25Difference between transition and animation?
Transition moves between two states (e.g. on hover); animation uses @keyframes and can run multiple steps automatically.
26What does the transform property do?
Moves, rotates, scales or skews an element without affecting the normal page flow.
27What is a CSS custom property (variable)?
A reusable value defined with -- and read with var(), e.g. --primary and var(--primary).
28What does calc() let you do?
Mix units in one expression, e.g. width: calc(100% - 40px).
29What is the difference between a CSS framework and a preprocessor?
A framework (Bootstrap, Tailwind) ships ready-made styles/classes; a preprocessor (Sass, Less) is a language that compiles into plain CSS.
30Why should you avoid overusing !important?
It overrides the normal cascade, making future styles harder to predict and override.

Final Checklist Before You Ship a Page

  • Responsive on mobile, tablet and desktop
  • Consistent spacing and typography scale
  • Keyboard focus states are visible
  • Images scale correctly with max-width: 100%
  • No unwanted horizontal scroll
  • Reusable classes instead of one-off styles
  • box-sizing: border-box applied globally
  • Motion is smooth but not excessive
